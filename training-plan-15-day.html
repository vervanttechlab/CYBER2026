Scope declaration

TESDA published Competency Standards for Cyber Threat Monitoring Level I — the qualification definition and the units of competency — but no Training Regulations. There is no promulgated Section 3 carrying the “Level I” name, so no official nominal duration, trainee entry requirement or tools list exists for it. The hour figures and learning-outcome sequencing below are benchmarked against the Cyber Threat Monitoring NC I Training Regulations (ICTCTM124, promulgated 13 November 2024), whose two core units are identical in element and performance criteria.

That TR budgets 271 hours in-centre plus 120 hours of Supervised Industry Learning. This plan is 120 hours. It is therefore an intensive bridging or upskilling course — right for graduates, career shifters and in-service IT staff preparing for national assessment — and not a substitute for a WTR-registered full program. Where registration is the goal, use this outline as the core-competency spine and add the missing in-centre hours and the full SIL.

The low-spec bench

every substitution runs on the trainee machine described below

The NC I TR specifies an i7 8th-gen workstation with 16 GB RAM per trainee, a 64 GB server, licensed SIEM, an enterprise EDR console and commercial vulnerability scanners. This plan targets the machine a training centre actually has — and splits the bench in two, so the heavy component sits on one machine instead of twenty.

Tier 1 · every trainee machine

The portable bench

Intel i3/i5 4th–8th gen or AMD equivalent · 4–8 GB RAM · 128–256 GB SSD or HDD · integrated graphics · Windows 10/11, Pro preferred

Everything a trainee runs locally: Defender driven from PowerShell, Sysmon, Hayabusa, the Sysinternals and Zimmerman tools, Nmap, and the Wazuh agent. No hypervisor, no service, no admin rights beyond the install. This tier alone satisfies every performance criterion in both core units.

Tier 2 · one shared server box

The class SIEM — VirtualBox + Wazuh OVA

Any one machine with 4 physical cores · 12 GB RAM or more · 120 GB free SSD · VT-x / AMD-V enabled in BIOS

The instructor machine, a spare desktop, or a small server runs VirtualBox hosting the Wazuh all-in-one OVA. Trainees never install it — they enrol an agent and open the dashboard in a browser. One box turns the whole room into a real SOC.

Assessment, entry, and what this plan does not do

Assessment methods — both core units

  • Demonstration with oral questioning
  • Written examination
  • Portfolio with interview
  • Context: the actual workplace, or a TESDA Accredited Assessment Center
  • Resources to be provided: appropriate supplies and materials, applicable equipment, appropriate software, and a workplace or assessment area

Trainee entry requirements

  • Completed basic education or its equivalent under existing DepEd policy
  • Able to communicate in any form
  • Knows how to use and operate a computer and a mobile device on a current operating system
  • Physically able to manipulate a computer input device
  • Institutional requirements — educational attainment, work experience — are set by the delivering centre and are additional to these.

Deliberately out of scope

  • Supervised Industry Learning (120 h) — arrange separately with a partner SOC or IT department; this plan cannot substitute for it
  • SIEM administration. Trainees consume the Wazuh dashboard as an L1 analyst does — they do not tune rules, write decoders, size the indexer or maintain the server. That is engineering work above this qualification
  • Incident response and containment — that is Computer Security Incident Handling Level I, a separate qualification
  • Threat mitigation — Cyber Threat Mitigation NC II, a separate qualification
  • Live malware handling of any kind on classroom hardware

Room-level requirements

  • One server box — 4 physical cores, 12 GB RAM or more, 120 GB free SSD, VT-x/AMD-V enabled — running VirtualBox and the Wazuh OVA, on a static IP with a bridged adapter
  • One isolated lab subnet with its own router or switch — scanning targets never leave it, and the Wazuh server sits inside it
  • Written authorisation from the centre for every scanning exercise, filed with that day’s evidence
  • Internet access for browser-based intel, ATT&CK Navigator, CVE feeds and the ticketing tier
  • Hyper-V and Windows Sandbox off on the server box; Sandbox on for the trainee machines that will use it
  • Whiteboard, projector, and a USB drive holding the portable toolset
